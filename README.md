# o101

**o101** is a decommissioned C# project focused on building a private server framework inspired by *Wizard101* and *Open101*. It contains custom serialization, packet handling, and server-side networking logic.

> ⚠️ This project was officially discontinued on October 23, 2019. Provided as-is for educational and archival purposes.

## Features
- Basic server infrastructure
- Packet serialization/deserialization
- Experimental networking logic
